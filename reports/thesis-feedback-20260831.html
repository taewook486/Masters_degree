# 지적 사항 수정 전 수정 후
완료 §2.5 선행연구 요약이 빈약함. 관련 연구 5편 이상 추가하고 비교표를 만들 것 본문 1문단(국문 97단어). 절 내 인용 0건. 비교표 없음 3문단으로 재작성 + Table 2.1 신설(10개 연구 × 5축). 선행연구 6편 추가
완료 WCA 가중치의 임의성. 문헌으로 근거를 대거나 임의성을 줄일 것 “외부 임상 문헌이나 Delphi 합의 없이 연구자가 임의로 설정한 것”이라고 자백만 함 가중 원리는 ACR RADPEER[17]의 임상적 유의성 등급화 관행에 근거함을 명시. 수치는 가중 체계 5종 민감도 검증(Table 4.4a 신설)
완료 학습 시간 버그. “버그가 있다”고 넘기지 말고 재계산해 반영할 것 표 4.2a에 시간 열 자체가 없음. 버그는 표 아래 각주로만 서술 표 4.2a에 train_runtime_sec 기준 시간·SD 열 추가. 각주는 측정 기준 설명으로 교체. 75조건 전수 재집계
완료 선행연구와 직접 비교 한계. LLaVA-Med와 동일 기준(Recall) 수치를 부록에라도 추가할 것 “Open-ended는 비교할 수 없다”며 척도 차이를 이유로 비교를 회피 LLaVA-Med v1.0.0 채점 함수를 재현해 재채점. 표 4.4b에 open-ended 행 신설 + 부록 C(재현 절차·기준별 대조)

3번은 전제가 사실과 달랐습니다

“본문의 통계표를 재계산하라”는 지시였으나, 표 4.2a에는 애초에 시간 열이 없었습니다(subset_ratio / 학습 샘플 수 / Overall Acc 3열). 버그는 표 아래 각주로만 서술돼 있었습니다. 그래서 재계산할 표를 만드는 방향 — 각주를 지우고 정상 수치를 표에 편입 — 으로 반영했습니다.

4번 · 동일 기준 주관식 재채점

LLaVA-Med v1.0.0의 calculate_f1score recall 성분을 그대로 재현해, 저장돼 있던 예측에 채점 기준만 바꿔 적용했습니다. 모델 재실행은 없었습니다.

결과는 본 연구에 불리합니다

척도를 맞춰 놓아도 주관식은 세 데이터셋 모두 LLaVA-Med가 10~27%p 앞섭니다. 객관식에서 SLAKE가 대등했던 것(85.26 vs 85.34)과 대비되므로, “2B 모델이 7B 의료 특화 모델과 대등하다”는 해석을 객관식에 한정해야 합니다. §4.4.6과 §5.2의 기여 서술을 그에 맞게 좁혔습니다.

다만 비교 불가라고 회피하는 것보다 열세를 수치로 제시하는 편이 심사에서 방어에 유리하다고 판단했습니다.

재현 충실도

원본 calculate_f1score를 참조 구현으로 옮겨 두고 실제 예측 12,797쌍 + 경계 사례 8건을 차분 대조한 결과 불일치 0건이었습니다. 정규화 테이블은 출처를 밝혀 src/evaluate/vendor/에 인용했고, 검증 테스트 18건이 함께 커밋돼 있습니다.

지적 목록 밖 정정 지도교수 확인 필요

4번을 반영하다 발견한 사항입니다. §3.8.1이 BERTScore F1 ≥ 0.7을 “정확도·통계 검정의 유일한 결정 지표”로 서술했으나, 실제 정답 판정은 compute_open_accuracy(정규화 후 완전 일치 또는 정답 문자열 포함)이고 BERTScore는 병기 지표입니다.
